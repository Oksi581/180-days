Чтобы установить на iPhone как приложение:
1. Разместите папку на любом HTTPS-хостинге.
2. Откройте ссылку в Safari.
3. Нажмите Поделиться → На экран «Домой» → Добавить.

Все задачи и прогресс хранятся локально на устройстве в браузере.
